COMPLEXLEARN login and role-selection starter

HOW TO RUN
1. Extract this ZIP file.
2. Open the COMPLEXLEARN_login folder.
3. Double-click index.html. It should open in Chrome or Edge.

FLOW
1. User enters their name (email is optional).
2. User chooses Student or Teacher.
3. The COMPLEXLEARN dashboard opens.

IMPORTANT
This is a front-end demonstration. It does not create real accounts or securely authenticate users.
For real login, connect a trusted authentication provider such as Firebase Authentication and configure it securely.
The dashboard feature tiles are visual placeholders; the full AI, tests, library, news and reminder functions need to be built and connected.
