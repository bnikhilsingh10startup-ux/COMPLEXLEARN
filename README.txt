COMPLEXLEARN - Starter website

HOW TO RUN
1. Extract the ZIP file.
2. Open the complexlearn folder.
3. Double-click index.html. It should open in Chrome or Microsoft Edge.

FILES
- index.html: website pages and layout
- css/style.css: colours, layout and responsive design
- js/app.js: navigation and interactive features

IMPORTANT
- The doubt solver is an offline sample demo, not a real AI service.
- News headlines are sample content, not live news.
- Reminders are stored in this browser. Keep the page open for alarm checks.
- For a real AI service or live news, add a secure backend. Never put private API keys in browser JavaScript.
- Some library links open external learning websites.
